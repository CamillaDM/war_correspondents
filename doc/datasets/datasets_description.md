# Contenu du dossier "datasets"


Ce dossier contient les données des tables autours de dix objets "person" choisis au hasard. 

1. SQLite Database
    Le fichier [warcorrespondents.db](./warcorrespondents.db) est la base de données relationnelle complète contenant les tables, les relations et les views SQL. Elle contient une dizaine de lignes par table, afin de valider la structure. 

2. Exportation d'une table
    Le fichier [pursuit_exporttable.csv](./pursuit_exporttable.csv) est l'exportation de la table de liaison "pursuit". Il permet de démontrer la capacité à gérer les informations sous forme de données numériques structurées.
