# Présentation des queries

Ce dossier contient les scripts permettant de transformer les données brutes en informations exploitables pour nos questions de recherche.

1. View career chronology
    Cette vue permet d'accéder à l'ensemble des trajectoires professionnelles de notre population. 


2. View event gender distribution
    Cette vue produit des statistiques pour chaque conflit identifié par un tag. Elle permet d'illustrer, ou non, une disparité genrée dans la couverture de certains types de conflits ou à certaines périodes.
